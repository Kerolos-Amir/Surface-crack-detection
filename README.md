# Surface-crack-detection
Deep learning project for surface crack image classification using CNN
Surface Crack Detection Using Deep Learning

Project Overview

This project uses Deep Learning to classify surface images into two categories: cracked and non-cracked.

Technologies Used

* Python
* TensorFlow / Keras
* Convolutional Neural Networks (CNN)
* NumPy
* Matplotlib

Project Workflow

* Load and preprocess the image dataset.
* Prepare the data for model training.
* Build and train a CNN model.
* Evaluate the model’s performance.

Project Goal

The goal is to detect surface cracks automatically using image classification.

How to Run

1. Install the required Python libraries.
2. Prepare the dataset.
3. Run the project notebook or Python script.
